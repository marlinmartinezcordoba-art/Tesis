# Ontología RiC-O 1.1

`RiC-O_1-1.rdf` es la ontología oficial Records in Contexts – Ontology 1.1 del
Consejo Internacional de Archivos (ICA-EGAD), copiada sin cambios del
repositorio oficial (`ontology/current-version/RiC-O_1-1.rdf`).

RICORA la usa como fuente primaria para verificar la conformidad de lo que
exporta (`ric/conformidad.py`): que cada propiedad y cada clase existan en
RiC-O, que las propiedades de objeto apunten a entidades y las de dato a
textos, y que el dominio y el rango de cada propiedad se respeten.
